# Fuentes de los documentos

Los PDFs no se incluyen en el repositorio (son de terceros y se pueden volver a
descargar). Para reproducir el ejemplo de seguros, guarda estos archivos en esta
carpeta con estos nombres:

| Archivo | Origen |
|---|---|
| `ley_contrato_seguro_BOE.pdf` | Ley 50/1980 de Contrato de Seguro, texto consolidado del BOE: https://www.boe.es/buscar/pdf/1980/BOE-A-1980-22501-consolidado.pdf |
| `caser_hogar_condiciones_generales.pdf` | Condiciones generales Caser Hogar: https://www.caser.es/documents/473773/15908398/condiciones-generales-hogar.pdf |
| `ing_naranja_hogar_condiciones_generales.pdf` | Condiciones generales seguro de hogar Naranja (ING): https://www.ing.es/sobre-ing/pdf/condiciones-generales-seguro-hogar-naranja.pdf |
| `asisa_salud_condiciones_generales_2017.pdf` | Condiciones generales ASISA Salud (versión de 2017): https://www.asisa.es/empresas/fecantri/pdf/CCGG%20ASISA%20Salud%202017%20-%20AIG3970.pdf |

Descargados el 17 de noviembre de 2026. Las condiciones de las aseguradoras
cambian con el tiempo: sirven para probar el sistema, no como asesoramiento.

Para otro dominio, deja aquí otros PDF, .txt o .md y ajusta `config.yaml`.
